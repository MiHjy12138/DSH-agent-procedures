# 质量预算与 CI

> 这份文档只讲三件事：成本上限、审计自动化、评审的适用范围。
> 原则是**别再加一套索引/记忆**。

## 1. Token 预算写进检查

- 全局钩子 ≤ 1.5 KB；
- `INDEX.md` ≤ 1 KB，并验证它不随卡数增长；
- 单卡 ≤ 2 KB —— 与 README 的硬纪律一致，**不放宽到 3 KB**；放宽会让膨胀静默合理化。
- 上述数字目前靠评审时人工核对；接入 CI 后改为自动检查。

## 2. audit 进 CI

- `tools/procedures-audit.mjs` 只读、可直接跑：检查必填段、触发行、链接、体积、过期线索；
- 仓库**目前没有 CI**（无 `.github/`）：先按「卡库变更时手动跑一遍」，等加了 workflow 再接；
- 更早的拦截点是 pre-commit —— 比 CI 离开发者更近。

## 3. review 保持可选

- `procedures-review.mjs` 依赖 DSH 会话日志，是 **DSH-only**，不要写成跨 harness；
- 放在可选附件，不阻塞主线；
- 没有会话日志时，用 `_layers.md` 的时间阈值降级。

## 约束

- 不新增逐卡索引 / catalog；
- 需要搜索时，用文件名、触发行、正文定向搜；
- 本地工作台可以用派生索引，但不提交、不注入、不常驻；
- 不自动捕获、不自动写回、不加全局钩子。
