# procedures · 经验指针

> **用法**：开工前扫一眼下表。任务撞上左列现象，才去 read 右列那张卡；撞不上直接跳过。
> **长法**：收尾踩了新坑 → 同类卡有就补进去，没有就照 `_模板.md` 新建，并在此加一行。
> **别做的**：不主动扫描经验库；卡片正文不抄进来；**不把读卡包成工具** —— 工具 schema 本身常驻 system prompt，等于把「按需」偷换成「常驻目录」。

## 分类怎么划

按**你实际会撞上的场景**划，不是按学科划。常见的：

- `抓取-` 网页 / 接口 / 数据获取
- `文件-` 读写、格式转换、批量处理
- `脚本-` 命令行、执行环境、编码
- `工具-` 环境配置、依赖、部署

前缀写进文件名（`脚本-双引号插值.md`），这样 `ls` 目录时也能一眼看出分类 —— 卡少的时候，**目录本身就能当索引用**。
