# procedures · 索引

> **这不再是卡片目录。** 卡名就是索引（`分类-现象`），检索靠文件名 + 卡内 `> **触发**：` 那一整行现象词。
> **新卡不必在这里登记** —— 加一张卡只改文件名，不用回来改这张表。

分类按**你实际会撞上的场景**划，不是按学科划：`抓取-` 网页/接口 / `文件-` 读写与格式转换 / `脚本-` 命令行与编码 / `工具-` 环境与依赖。
前缀写进文件名（`脚本-双引号插值.md`）—— 列目录时一眼就能分出类。

## 只写「卡名分不出来」的那几对

| 现象 | 读哪张 |
| --- | --- |
| <现象 A：写成任务里会出现的词，不是主题词> | <分类>-<现象> |
| <和 A 长得很像、但根因不同：现象 B> | <分类>-<现象> |

## 什么时候才往这里加一行

只有一种情况：**两张卡的现象词太像，光看卡名判断不出该读哪张**。

其余一概不加 —— 现象词归卡名与卡内「触发」行。索引一旦开始逐卡登记，就会随卡数线性增长，还会跟卡里的触发行变成两份真相。

> **别把「读卡」包成工具** —— 工具的 schema 常驻 system prompt，注册工具 = 把「按需」偷换成「常驻目录」。
