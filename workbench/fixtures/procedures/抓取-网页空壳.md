# 抓取-网页空壳

> **触发**：页面返回 200，但正文抓不到，只有 SPA 空壳（常见 `<div id="root">`）
> **验证**：正文选择器能拿到 > 500 字，而不是空字符串。

## 首选

用浏览器渲染，等 `networkidle` 后再取正文。

## 被挡时

1. 直接请求 JSON / AMP 接口。
2. 用分享页的 `og:description` 兜底。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| 只加 User-Agent | 返回的仍是空壳 HTML |
| 只等 1 秒 | SPA 还没挂载 |

## 注意

- 200 不代表正文存在。
- 判据是正文长度，不是状态码。
